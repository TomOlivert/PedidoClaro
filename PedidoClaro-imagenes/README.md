# Imágenes de PedidoClaro

Esta carpeta reúne los recursos visuales del proyecto para conservarlos junto con la documentación en GitHub.

| Archivo | Uso |
| --- | --- |
| `logo-pedidoclaro.png` | Logotipo compartido para la cabecera y la página Inicio de WordPress. |
| `pedido-claro-hero.png` | Ilustración de una tienda que recibe pedidos desde un celular. |
| `pedidoclaro-proyectos-hero.png` | Ilustración de una compra en una panadería para la página del proyecto. |

Los dos últimos archivos son imágenes de apoyo visual para presentar la propuesta. El sitio WordPress no se sincroniza automáticamente con este repositorio.
