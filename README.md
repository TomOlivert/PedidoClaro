# PedidoClaro

**Propuesta académica de un sitio web en WordPress para ayudar a pequeños negocios a recibir pedidos claros desde el celular.**

[Ver el sitio publicado](https://olivertportfolio.gamer.gd/) · [Conocer la propuesta](https://olivertportfolio.gamer.gd/proyectos/)

## Problema

En muchos pequeños negocios, los pedidos llegan por llamadas y mensajes dispersos. A veces faltan datos, se repiten preguntas sobre precios o disponibilidad y cuesta recordar qué solicitó cada cliente.

## Propuesta

PedidoClaro plantea una vitrina digital sencilla donde el cliente consulta productos o servicios y envía una solicitud ordenada. El negocio revisa los datos y confirma el pedido y su disponibilidad.

### Recorrido propuesto

1. El cliente revisa el catálogo, los precios y los detalles.
2. Completa un formulario breve con lo que necesita y sus datos de contacto.
3. El negocio recibe la solicitud, verifica la disponibilidad y se comunica para confirmarla.

## Alcance

**Implementado en esta etapa:** sitio informativo en WordPress que presenta el problema, la idea, el recorrido y un canal de contacto.

**Propuesto para una siguiente etapa:** catálogo administrable, registro centralizado de solicitudes, estados del pedido y avisos al cliente. Estas funciones todavía no forman parte del sitio publicado.

## Objetivo

Reducir pedidos incompletos y conversaciones repetidas con una experiencia clara y cómoda desde el teléfono. La propuesta está dirigida a clientes y pequeños negocios que atienden por medios digitales.

## Tecnologías y herramientas

- WordPress para el sitio publicado.
- Elementor para maquetar páginas.
- GitHub para documentar la propuesta y llevar el control de cambios del proyecto.
