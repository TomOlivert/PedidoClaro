# PedidoClaro

**Propuesta académica de un sitio web en WordPress para ayudar a pequeños negocios a recibir pedidos claros desde el celular.**

[🌐 Sitio publicado](https://olivertportfolio.gamer.gd/) · [📋 Página del proyecto](https://olivertportfolio.gamer.gd/proyectos/) · [✉️ Contacto](https://olivertportfolio.gamer.gd/contacto/)

## El problema

En muchos pequeños negocios, los pedidos llegan por llamadas y mensajes dispersos. A veces faltan datos, se repiten preguntas sobre precios o disponibilidad y cuesta recordar qué solicitó cada cliente.

## La propuesta

PedidoClaro plantea una vitrina digital sencilla donde el cliente consulta productos o servicios y envía una solicitud ordenada. El negocio revisa la información y confirma disponibilidad y siguientes pasos.

### Recorrido propuesto

1. El cliente revisa la oferta, los precios y los detalles.
2. Completa una solicitud breve con lo que necesita y sus datos de contacto.
3. El negocio revisa la solicitud, verifica disponibilidad y se comunica para confirmarla.

## Alcance

- **Implementado en esta etapa:** sitio informativo en WordPress que presenta el problema, la propuesta, el recorrido y un canal de contacto.
- **Propuesto para una siguiente etapa:** catálogo administrable, registro centralizado de solicitudes, estados del pedido y avisos al cliente. Estas funciones todavía no están implementadas.
